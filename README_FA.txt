پرتفوی من — نسخه آزمایشی موبایل (PWA)

این بسته یک نمونه اولیه وب‌اپلیکیشن موبایل برای مدیریت پرتفوی بورس ایران است.
امکانات:
- ثبت نماد دلخواه و قیمت روز دستی
- ثبت خرید و فروش، تعداد، قیمت و کارمزد
- محاسبه موجودی، میانگین بهای تمام‌شده، سود/زیان باز و تحقق‌یافته
- نمودار ترکیب پرتفوی
- ذخیره محلی اطلاعات در مرورگر
- خروجی CSV معاملات و پشتیبان‌گیری/بازیابی JSON
- رابط فارسی راست‌چین و سازگار با صفحه موبایل

اجرای سریع برای آزمایش:
- فایل index.html را در مرورگر باز کنید. ممکن است قابلیت نصب و آفلاین در این حالت فعال نشود.

برای نصب به‌صورت PWA:
- فایل‌ها باید روی یک وب‌سرور با HTTPS میزبانی شوند (یا در localhost اجرا شوند).
- سپس سایت را در Chrome اندروید باز کنید و از منوی مرورگر گزینه Install app / Add to Home screen را بزنید.
- در iPhone، سایت را در Safari باز کنید و Share > Add to Home Screen را انتخاب کنید.
- این بسته به‌تنهایی روی یک آدرس اینترنتی منتشر نشده؛ میزبانی و HTTPS باید جداگانه انجام شود.

محدودیت‌ها:
- قیمت‌ها دستی‌اند و هیچ اتصال زنده‌ای به TSETMC یا کارگزاری وجود ندارد.
- اطلاعات فقط در همان مرورگر و دستگاه ذخیره می‌شود؛ بین دستگاه‌ها همگام‌سازی نمی‌شود.
- پاک شدن داده‌های مرورگر ممکن است اطلاعات محلی را حذف کند؛ از پشتیبان JSON استفاده کنید.
- محاسبات سود تحقق‌یافته نسخه اولیه‌اند؛ پیش از اتکا با گزارش کارگزاری تطبیق دهید.
- از یک واحد پولی (ریال یا تومان) به‌صورت یکنواخت استفاده کنید.
