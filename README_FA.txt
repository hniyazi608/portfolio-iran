نسخه به‌روزشده برنامه پرتفوی من

برای انتشار، فایل‌های index.html، manifest.json، sw.js و پوشه icons را در ریشه مخزن GitHub Pages جایگزین کنید. پیش از جایگزینی، از اطلاعات فعلی برنامه خروجی JSON بگیرید. نسخه جدید اطلاعات قبلی ذخیره‌شده در مرورگر را نگه می‌دارد و قابلیت ثبت سود نقدی مجامع را اضافه می‌کند.
